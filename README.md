# Housing Completed

Author: Korivash
Version: 1.5.0

Housing Completed is a standalone housing collection addon with:
- Residence preview with Dressing Room fallback.
- Vendor inventory browser (click vendor rows or use preview button).
- Crafting materials and reagent cost calculations using internal recipe/reagent datasets.
- Economy integration with Auctionator/TSM-compatible providers.

## Commands
- `/hc`
- `/housing`
- `/housingcompleted`
- `/hc settings`
- `/hc minimap`

## Install
1. Put `HousingCompleted` in `World of Warcraft/_retail_/Interface/AddOns/`.
2. `/reload`.
